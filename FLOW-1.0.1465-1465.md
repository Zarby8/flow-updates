# FLOW 1.0.1465

**You can now see the NAS copy happen.** After PRODUCE BREAKDOWN the filing step
used to give no sign of life, so there was no way to tell whether your movie
actually reached the NAS. Now the export sheet shows the real copy while it runs
— the destination, how much has moved, and the percentage — and the result is
reported in FLOW itself, not only inside a sheet that closes.

**Filing is on by default.** Completed client breakdowns are filed automatically
into their existing game folder. If it cannot file, it says so with the reason and
keeps your local movie. If filing is switched off, the completion sheet states
that clearly and gives you **FILE TO NAS NOW** in one click, so a finished export
never looks like a delivery that quietly did nothing.

**Safer by construction.** FLOW still never creates or guesses a client or game
folder, and it refuses to overwrite a different file that is already sitting in
the game folder.
