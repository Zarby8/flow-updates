# FLOW 1.0.1274

- Adds FLOW support for native packages created by the owner-authenticated provider-media Import Edge.
- Shows whether a provider package is awaiting a Brain match or has an associated Brain game, with access to supplied title and artwork.
- Preserves provider identity and authored project content when an exact Brain association is added later.

This app update requires the matching Import Edge service for automatic SHIFTS package creation. Real receiver playback acceptance is tracked separately.
