# FLOW 1.0.1112

- IQ Library left panel now shows up to 48 relative metrics when typing (was capped at 10).
- Clip multi-selection: Shift+click for range, Cmd+click to toggle, Cmd+A to select all visible.
- Database load cached: processed clips and the parameter index are serialized to JSON so subsequent loads skip Realm conversion and index rebuild.
- Breakdown Export overlay no longer shows prohibited auto-tags (GAME DATE, PERIOD, ASSISTS, CODE, GOAL SECONDS, etc.) that the live IQ Library overlay already hid.
- IQ Library window opens on the display showing the main FLOW window instead of whichever screen has the cursor.
- .flowaipkg files show the FLOW icon in Finder instead of a generic document icon.
