# FLOW 1.0.1550

**SINCE LAST BREAKDOWN is one click.** When FLOW can place the client's last
breakdown on an exact Brain game, the button goes straight to Ghost's Since Last
Breakdown report. That report covers every game since the last breakdown in one
document. It opens in FLOW's viewer, and BOB reads it right away: one synthesis
of the whole window, plus coaching targets for the game loaded in FLOW. The eye
under the button now builds the report instead of saying no PDF exists yet.

**FLOW says which breakdown it cannot place.** If Brain has no game for the
client's most recent breakdown project, FLOW names that project instead of
quietly measuring from an older breakdown. An older breakdown would have
stretched the report back over games you had already covered.

**Jev picks what to lead with in COACHES NOTES.** A JEV · TEACHABLE NOW strip
at the top of the notes sheet suggests which of your own note lines to open
with. Pressing a suggestion only moves that line to the top; Jev never rewrites,
rewords or adds text, and nothing from it reaches the family PDF.

**Diagnostics shows where the Jev key comes from.** Settings → Diagnostics now
reports whether Jev is on and where its key comes from (environment or
Keychain), never the key itself.
