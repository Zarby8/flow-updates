# FLOW 1.0.1479

**Every label is now editable — and the defaults are untouched.** The three
profile labels at the top of the Code Window (player, opponent, date of game) used
to be read-only. Now every label is the same kind of row: click one to rewrite it,
drag the arrows to reorder, ✕ to remove it, and RESTORE DEFAULTS to put the three
back in order. A label you have not touched still follows the client profile, so
correcting a jersey number or an opponent updates every clip — and a label you have
written keeps what you wrote. Hiding a row is not a delete: the three can always
come back. Labels stay with the client, not the window tab, and your existing labels
carry over untouched.

**The rail's LABELS list renames in place.** Tap a label in LABELS · DRAG TO ORDER
(or use RENAME LABEL in its menu) to change its name — which is exactly what burns
into clip text and what the stringing model keys on. The pencil still opens the full
editor for colour and stringing. So a label such as `#PlayerName` can be renamed,
unstrung or deleted without leaving the rail.

**Create a clip, press Enter, start typing.** Every way of making a clip — the marked
clip, a single code-button press, and the two-press range — now selects what it made
and hands the timeline the keyboard, so Enter drops you straight into that clip's
note. Before this, a clip made by *clicking* a button left Enter with nothing to do.

**Manual cuts are accepted.** A hand-cut game video with no InStat record can now be
registered through the provider-media intake. It carries owner-authored
`manual-…` route keys instead of provider IDs, so a manual cut can never be mistaken
for a provider record, and re-running the same cut replays it rather than creating a
second one.
