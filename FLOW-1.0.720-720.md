# FLOW 1.0.720

This release adds review-before-send voice input while preserving FLOW's production coaching workflow.

- Adds push-to-talk dictation to BOB's composer. Transcripts remain editable drafts and are never sent automatically.
- Keeps TAG voice input staged-only behind the existing sole-writer safety gate.
- Cancels microphone, transcription, and fallback work when voice input is disabled or its view closes.
- Keeps voice input off by default until installed microphone UAT is accepted.
- Retains canonical GHOST client identity, exact-name code-button timeline rows, native video playback, package save/reopen, real-media export, Meeting Notes, and IQ Library playback.
- Preserves owner-only local storage plus transactional installation backup and rollback support.

The ML models remain advisory and are not promoted by this release.
